## 维护约定

- README 保持简短；操作方法放使用指南，工程约束放开发文档，同一规则避免多处展开。
- 功能变更直接更新现行说明，不追加“本轮修改”“测试通过数量”或过程时间线。
- 验收清单描述检查方法，不代表已经通过；需要留存的本地日志、截图和诊断输出放 `build/validation/`，不纳入 Git。
- 目录说明只描述文件夹用途：`docs/` 为现行文档，`docs/development/` 为开发维护文档，`website/` 为官网源码及其维护说明。
- 修改后运行 `python3 scripts/verify-docs.py` 检查本地链接。
