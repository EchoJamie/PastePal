# 使用指南

[返回文档索引](README.md)。下文列默认快捷键，可配置项以设置页面为准。

## 启动与权限

首次启动需要辅助功能授权；授权后只记录后续复制，不补录启动前内容。撤销权限会停止监听并关闭历史与截图。正常使用在菜单栏常驻，打开设置时显示 Dock 图标，关闭设置后收起。

安装或移动应用后，在固定位置重新确认辅助功能权限和登录启动。历史及图片保存在 `~/Library/Application Support/PastePal/`，设置保存在 `local.jamie.PastePal` 的 UserDefaults 域。Preview 和正式版共用这些数据，不要同时运行。

## 外观与语言

在“设置 → 常规”选择外观与语言。外观支持跟随系统、浅色、深色，切换立即生效；跟随系统会随 macOS 明暗模式自动调整。

语言支持跟随系统、简体中文、繁體中文和 English，重新打开应用后生效。跟随系统按 macOS 偏好语言顺序选择支持的语言，没有匹配时使用英文。语言设置只影响界面，不会转换历史内容或分组名称。

## 历史与搜索

| 操作 | 默认方式 |
| --- | --- |
| 打开历史 | ⌘⇧V |
| 选择记录 | ← / → |
| 使用记录 | 回车或双击，直接粘贴到原输入位置 |
| 纯文本使用 | ⌥↩，保留历史中的原格式 |
| 放大预览 | 空格 |
| 使用前九条 | ⌘1–9 |
| 搜索 | 点击放大镜、直接输入或 ⌘F；⌘V 可粘入关键词 |
| 切换完整历史与分组 | Tab / ⇧Tab；搜索中切换范围并保留关键词 |

搜索匹配全文、文件名、链接标题和复制来源，中文直接匹配，英文忽略大小写。图片不做 OCR。组内搜索可点击“组名 ×”移除范围，扩展到完整历史。

搜索中第一次回车完成搜索并回到卡片，再次回车才使用记录；Esc 恢复进入搜索前的范围与选择，卡片状态再按 Esc 关闭。输入法组词期间按键优先交给输入法。

普通系统 ⌘V 始终使用系统当前内容。没有独立“仅复制”入口；不能可靠恢复原输入位置时提示手动粘贴。浏览、搜索和预览不会改变剪贴板。

## 分组与保留

顶部 `+` 新建分组，单击标签进入、再次单击返回完整历史；双击改名，拖拽标签排序。按 ⌘G 选择加入的分组，也可拖动卡片到标签；一条记录可以属于多个分组。

分组内 Delete 只移出该组，完整历史中 Delete 永久删除记录。选中分组的 × 用于删除分组，需要确认。失去最后一个分组归属后，记录立即受当前保留策略约束。

新用户默认保留最近 30 天未分组历史，在“历史与存储”可改为天数或条数，两种方式二选一；首次切换条数的候选值为 10,000，已有用户保留原设置。时间从最近复制或使用计算。编辑完成即保存并应用，可能清理超出范围的未分组内容；已分组内容长期保留。“清空未分组历史”另有确认。

暂停记录跨重启保留，恢复后只记录后续复制。可在设置排除指定应用。

## 截图、标注与输出

设置中单独启用区域截屏并授予屏幕录制权限，默认 ⌘⇧A；菜单另提供“截取窗口”。窗口截图点击目标窗口后进入同一标注流程。

拖出选区后默认不启用工具；点击工具启用，再点停用，工具之间互斥。没有工具时拖动内部移动选区；边缘和八个控制点始终可以调整大小，即使用着其他工具也不例外。工具栏为图标，悬浮显示名称和快捷键，有适用参数时才展开第二行。

| 工具或操作 | 快捷键 |
| --- | --- |
| 选择、移动和修改已有标注 | M |
| 箭头、矩形、椭圆 | A / B / E |
| 画笔、文字 | P / T |
| 马赛克、模糊 | X / U |
| 撤销、重做 | ⌘Z / ⇧⌘Z |
| 贴图、美化并保存 | ⌘P / ⌘S |

选中标注可修改适用的颜色、粗细或字号；箭头拖动箭身移动、拖动端点调整，文字双击修改。遮挡工具可切换马赛克或模糊，以及弱、中、强三档；效果合成到输出像素。

- **复制**：使用工具栏复制按钮，写入剪贴板并按正常策略记录；暂停时不强制归档。
- **贴图**：无边框置顶，初始位置和逻辑尺寸与原选区一致。拖动移动，滚轮以约 5% 倍率分档缩放，最高 250%，以鼠标位置为缩放中心。最小长边 80 点，原图更小时保持其原始尺寸；命中区域至少 44 × 44 点。双击关闭，右键调整透明度或恢复 100%。
- **美化并保存**：调整背景、留边、圆角和阴影后保存 PNG。“返回编辑”或关闭预览恢复原选区、标注及撤销历史；取消保存对话框仍留在预览。

贴图和保存不自动写剪贴板或历史。Esc 取消截图；取消或失败不写入新图片。

## 内容与隐私边界

支持纯文本、独立 HTTP(S) 链接、常见颜色代码、RTF、含文字的标准 RTFD/HTML、PNG/TIFF/JPEG/GIF 及 Finder 文件引用。重复复制按原始表示去重并保留分组；纯文本使用不会生成历史副本。

Finder 文件只保存引用，不备份文件本体；源文件移动或删除后无法取回。富文本预览显示提取文字，GIF 预览只显示首帧，回贴保留原始内容。应用私有格式及复杂混排不保证支持；标记为 Concealed/Transient 的内容不归档。

历史不上传，HTML 内容不执行脚本或加载内嵌资源。只有整段为一个 HTTP(S) URL 时才直接请求该站点的标题、图标和预览，失败保留原链接，不持续重试。复制来源优先采用有效应用声明，否则按复制时的前台应用推定；推定会标识，无法判断时保持未知。
