# 架构与数据

[返回文档索引](../README.md)。应用采用 Swift、AppKit、SwiftPM 和系统 SQLite，无后端、账号或同步服务。

## 模块职责

| 模块 | 职责 |
| --- | --- |
| ClipboardMonitor / AccessibilityGate | 观察剪贴板变化、读取支持表示与来源，执行权限、暂停、排除和自身回写识别 |
| CaptureInbox / AppModel | 原始复制暂存、按序消费、串行历史操作、概览发布和保留维护 |
| HistoryStore | SQLite 事务、去重、排序、分组、保留策略及资源引用清理 |
| HistoryQueryResults / HistorySearchCoordinator | 独立只读查询、分页缓存、搜索合并与取消 |
| LinkMetadataFetcher / BoundedLinkDownloader | 链接元数据下载、接收预算、解析及本地缓存 |
| PanelController / 分组视图 / PasteCoordinator | 历史交互、分组管理、原输入位置恢复和粘贴目标核对 |
| ScreenshotController 及截图视图 | 屏幕捕获、选区与标注、PNG 输出、贴图和美化保存 |
| SettingsStore / 快捷键存储 / AppDelegate | 偏好、快捷键、应用生命周期和设置 Dock 行为 |

## 存储与主流程

数据根目录为 `~/Library/Application Support/PastePal/`，包含历史数据库、图片和 CaptureInbox；设置域为 `local.jamie.PastePal`。首次迁移从旧目录复制并校验后原子启用，新目录已有内容时不覆盖；偏好按缺失键补齐，旧数据保留为备份。

主流程：系统复制 → 原始表示暂存 → 串行历史入库 → 分页浏览 → 用户确认 → 回写系统剪贴板 → 恢复原位置粘贴。

暂存先写独立目录再原子改名，成功入库后删除；失败保留供后续复制或启动重试。消费队列只保留标记，worker 每批最多 8 条，逐条读取解码。使用、删除和清空以捕获序号建立屏障，先处理此前已接受的复制，避免旧内容在清空后重新出现。

记录保存稳定 ID、项目边界、原始表示、指纹、可搜索文字、来源及依据、时间和活动序号。按项目顺序、类型和字节去重，重复记录前移并保留分组。图片原字节和首帧缩略图独立落盘；Finder 只保存 URL 引用。SQLite 事务同步记录、分组及资源引用，事务成功后清理无引用资源。

剪贴板和 SQLite 不能共同原子提交，部分成功时必须如实反馈。真正发送粘贴前核对权限、剪贴板变化号、原应用、窗口和输入元素；目标改变则停止。截图复制经正常记录策略处理，贴图与保存不入历史。

## 保留与查询

新用户默认时间模式 30 天；已有条数设置继续沿用。时间以最近复制或使用的较新值计算滚动窗口，边界相等保留；条数按活动序号取最新 N 条。两种模式互斥，分组记录不参与淘汰。失去最后归属时在同一事务应用当前策略；启动及默认每 15 分钟执行时间保留维护。

常驻概览最多 128 条，完整历史独立分页，每页 64 条、最多缓存 4 页，并受 4 MiB 序列化摘要预算约束；概览不代表保留上限。摘要文字最多 1,600 字符，全文检索使用独立字段，原始表示按需读取。卡片图片缓存上限 24 MiB。

只读事务固定查询快照，关闭或更换结果时释放。搜索只保留执行中和最新待执行请求，通过 SQLite progress handler 取消旧读取，并过滤迟到结果；取消不影响写入连接。

## 网络与来源

只有完整 HTTP(S) URL 触发元数据请求，普通文字中的链接、HTML 内嵌资源和旧历史加载不主动抓取。临时会话不携带浏览器 Cookie 或登录态，最多并发 2 个页面任务；HTML 最多接收 1,000,000 字节前缀，图标与预览图超过 750,000 / 2,000,000 字节则拒绝。失败不持续重试；回调核对记录 ID、指纹、URL 及状态，不复活已删除记录。

有效来源声明优先，否则按复制和前台激活时序推定；歧义保持未知。网站身份和复制应用分开保存，不从内容猜来源。

## 已知限制与维护重点

- 剪贴板默认每 200 毫秒轮询，无法找回检查之间已被覆盖的复制；系统一次性读取和同步暂存大内容仍可能阻塞主线程或产生内存峰值。
- 写入后的全量资产扫描、条数清理、substring 搜索和深页 OFFSET 存在规模成本，仍需优化及测量。
- 长期开启只读快照可能延迟 WAL 回收；关闭或替换查询必须释放事务。
- CaptureInbox 没有总磁盘容量预算，网络接收预算也不是整个进程内存上限。
- 设置隐藏时停止页面刷新，但辅助功能权限检查、剪贴板轮询和保留维护仍运行；短时采样不能证明长期资源稳定。
- 真实多屏、输入法、跨应用焦点和长期耗电需在目标设备检查，不能由离屏渲染或单元测试推断。

## 外观与本地化

外观由 `SettingsStore.appearanceMode` 持久化并应用到 `NSApplication.appearance`；跟随系统不设置应用覆盖值。设置中的语言写入当前应用的 `appLanguage` 与 `AppleLanguages`，恢复跟随系统时移除应用语言覆盖，重启后统一生效。

`PastePalLocalization` 提供简体中文文案键、英文和繁体中文资源及插值处理；用户内容作为参数保留原文。新增界面文案须同时补齐两个翻译表。打包时将其资源 Bundle 一并放入应用的 `Contents/Resources`，运行时优先从应用包读取。
