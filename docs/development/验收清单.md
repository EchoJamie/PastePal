# 验收清单

[返回文档索引](../README.md)。用于待交付版本，不记录历史执行结果；按改动范围选择检查项，正式交付前核对完整核心流程。

| 范围 | 检查内容 |
| --- | --- |
| 权限与启动 | 未授权不监听；授权只记录后续复制；撤销后停止监听与截图；固定安装路径下登录启动正常 |
| 记录与取回 | A/B/A 去重、原格式与多项目顺序、纯文本使用、重启保留；原窗口失效不误贴 |
| 搜索与输入法 | 全文、来源和文件名匹配；第一次回车完成搜索、第二次使用；组词、候选、取消和改键正常 |
| 分组与删除 | 新建、改名、排序、拖入和多组归属；组内移除与永久删除区分；删除确认及焦点恢复正确 |
| 保留与恢复 | 天数/条数互斥、旧设置兼容、分组保护；失去最后归属重新清理；暂存失败、重试及清空屏障正确 |
| 内容兼容 | 富文本、透明 PNG、GIF 原动画、多文件引用；源文件失效不覆盖系统剪贴板；链接断网仍可用 |
| 截图交互 | 区域/窗口与 Retina、多屏负坐标；工具默认停用且互斥；边缘随时缩放；光标、参数和撤销联动 |
| 截图出口 | 复制遵守暂停策略；美化保存可返回原会话；贴图保持原位置和尺寸，滚轮缩放至 250%、双击关闭 |
| 外观与生命周期 | 浅深色、紧凑窗口、全屏、多屏、降低透明度；设置 Dock 显隐、重开分类保持；关闭窗口释放资源 |
| 常驻资源 | 按实际数据规模测量复制、搜索、窗口循环、CPU、footprint、唤醒与磁盘增长；记录采样时长和睡眠情况 |
| 打包 | 包名、版本、源码对应、开发签名及独立位置资源加载；Preview/正式包保持单实例；如交付 DMG，执行镜像完整性校验 |

自动化命令见[开发指南](README.md)。实机检查包含真实物理输入及常用应用，合成图片、受控测试和单次内存读数不能替代这些场景。应用当前使用开发签名，公开分发另需确认签名、公证及下载渠道。
